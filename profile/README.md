Gas costs were brutal. The reentrancy vulnerability sat open.
Marketplaces couldn't even recognise the NFTs.
The standard never got officially recognized.

It was buried.

**We dug it up.**

### What we built

**ERC-451** — a leaner, cheaper, safer semi-fungible token standard.
Built from the ashes of ERC-404. Named after HTTP 451: Unavailable For Legal Reasons.

| Improvement | Result |
|-------------|--------|
| Standard transfer | 55–60% cheaper |
| Multi-token transfer | 92–95% cheaper |
| Exemption toggle | 98% cheaper |
| Reentrancy guard | Added |
| Marketplace compatibility | Fixed |
| Circulating supply tracking | Fixed |
